# Cruise Ship Lawyer Lead Site (Starter)

A modular Next.js system for high-scale cruise accident lawyer pages.

## Current capabilities
- Dynamic route: `/cruise-lines/[cruiseLine]/[accident]`
- 30 cruise lines and 30 accident types
- Variant-driven intros + CTA labels for better uniqueness
- Reusable legal blocks (liability, evidence, FAQ, sources, disclaimer)
- Built-in lead form block
- Metadata + canonical + FAQ JSON-LD
- Basic page QA validator

## Run locally
```bash
npm install
npm run dev
```
